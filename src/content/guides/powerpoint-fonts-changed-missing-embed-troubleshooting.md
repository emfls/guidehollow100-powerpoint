> **읽기 전 참고** — Microsoft 공식 지원 문서를 바탕으로 작성했습니다. Windows·macOS·웹 버전의 메뉴와 지원 기능은 업데이트, 구독 및 조직 정책에 따라 달라질 수 있습니다. 실제 장비에서 모든 절차를 시험했다는 의미는 아닙니다.

다른 컴퓨터에서 파워포인트(PowerPoint) 파일을 열었더니 제목 글씨가 바뀌고, 문장이 두 줄로 밀리거나, 표 밖으로 글자가 튀어나온 적이 있나요? 원본 파일을 다시 꾸미기 전에 **글꼴 누락인지, 글꼴 포함 실패인지, 슬라이드 마스터나 파일 형식 문제인지**부터 구분해야 합니다. 글꼴을 포함해 저장하거나 대체 글꼴로 바꾸면 해결되는 경우가 있지만, 모든 글꼴을 무조건 포함할 수 있는 것은 아닙니다.

## 먼저 답부터: 상황별 해결 방법

| 증상 | 의심할 원인 | 먼저 할 일 |
| --- | --- | --- |
| 내 PC에서는 정상인데 상대 PC에서만 글꼴이 바뀜 | 상대 PC에 글꼴 없음, 포함되지 않은 글꼴 | 원본 복사본에서 글꼴 포함 설정 확인 |
| 한글이 네모(□)로 보이거나 글자 폭이 달라짐 | 글리프 미지원, 글꼴 대체 | 문제 글자의 글꼴 및 문자 지원 확인 |
| 저장할 때 글꼴을 포함할 수 없다는 오류 | 포함 권한 또는 글꼴 형식 제한 | 글꼴 포함 가능 여부 확인 후 교체 검토 |
| 전체 슬라이드의 제목·본문 서체가 다름 | 테마·마스터 글꼴 또는 일부 직접 서식 | 슬라이드 마스터와 개별 텍스트 서식 구분 |
| PDF로 보내면 정상, PPTX로 보내면 달라짐 | 편집 환경·설치 글꼴 차이 | 발표/열람용은 PDF, 편집용은 PPTX로 분리 |
| 웹에서는 다르게 보이지만 데스크톱은 정상 | 플랫폼 기능과 폰트 렌더링 차이 | 실제 발표할 환경에서 최종 확인 |

**가장 안전한 순서:** 원본 보존 → 문제가 발생하는 환경 확인 → 글꼴 식별 → 포함 또는 교체 → 새 이름으로 저장 → 다른 환경에서 재확인. 글꼴 파일을 출처 불명 사이트에서 다운로드하거나, 원본에 대량 치환을 바로 적용하지 마세요.

## 1단계. 원본을 복사하고 문제가 재현되는 환경을 적기

1. 원본 파일을 보존하고, 같은 폴더에 ‘발표자료-글꼴점검.pptx’처럼 복사본을 만듭니다.
2. 정상으로 보이는 기기와 깨지는 기기의 운영체제, PowerPoint 종류(Windows 데스크톱·Mac 데스크톱·웹), 사용 계정을 적습니다.
3. 문제가 생기는 슬라이드 번호를 세 장 정도 기록합니다. 제목, 본문, 표, 도형 속 텍스트 가운데 어디에서 발생하는지도 표시합니다.
4. 같은 파일을 데스크톱 PowerPoint와 웹용 PowerPoint에서 열었을 때 차이가 있는지 비교합니다. 다만 회사 자료라면 조직의 보안 정책에 허용된 저장·공유 환경에서만 시험하세요.
5. 비교 화면은 캡처해 둡니다. 글자 크기만 다른지, 서체 자체가 바뀌었는지, 줄바꿈·행간·도형 위치까지 달라졌는지 구분하기 쉽습니다.

같은 기기에서도 파일을 다시 열었을 때만 문제라면 다른 사람의 PC보다 **파일 저장 및 다시 열기 과정**을 먼저 점검해야 합니다. 반대로 특정 다른 컴퓨터에서만 바뀐다면 해당 컴퓨터에 글꼴이 없거나 설치된 글꼴 버전이 다른 가능성을 살펴보세요.

## 2단계. 어떤 글꼴이 사용됐는지 확인하기

글꼴이 깨진 텍스트 상자를 선택하고 **홈 → 글꼴**의 글꼴 이름을 확인하세요. 제목과 본문에 다른 글꼴이 쓰였을 수 있으므로 둘 다 기록합니다. 표 안의 텍스트, 도형 안의 텍스트, 붙여 넣은 텍스트도 별도로 확인하세요.

프레젠테이션 전체에 공통으로 적용된 글꼴인지 보려면 **보기 → 슬라이드 마스터**에서 마스터 및 각 레이아웃의 글꼴 설정을 살펴봅니다. 슬라이드 마스터에서 정한 글꼴과 개별 텍스트에 직접 적용한 글꼴은 다를 수 있습니다. 마스터만 수정했는데 일부 글자가 그대로 남아 있다면 직접 서식을 의심할 수 있습니다.

여러 텍스트에 같은 문제가 반복될 때는 PowerPoint에서 제공하는 글꼴 바꾸기 기능을 검토할 수 있습니다. Windows 데스크톱 버전에서는 일반적으로 **홈 → 바꾸기 → 글꼴 바꾸기** 경로로 접근합니다. 버전과 창 너비에 따라 메뉴 위치가 달라질 수 있습니다. 치환 전에는 반드시 복사본을 만들고, 치환 후 모든 슬라이드를 확인하세요.

## 3단계. Windows용 PowerPoint에서 글꼴 포함 설정하기

Microsoft는 다른 사람이 같은 글꼴을 설치하지 않았더라도 레이아웃을 유지할 수 있도록 프레젠테이션 파일에 글꼴을 포함하는 기능을 안내합니다. 지원되는 데스크톱 PowerPoint에서 다음 절차를 확인하세요.

1. 프레젠테이션 복사본을 Windows용 PowerPoint에서 엽니다.
2. **파일 → 옵션 → 저장**으로 이동합니다.
3. 화면 아래쪽의 **이 프레젠테이션을 공유할 때 충실도 유지** 영역을 찾습니다.
4. **파일에 글꼴 포함**을 선택합니다.
5. 공유 목적에 맞게 포함 방식을 결정하고 확인을 누릅니다.
6. 새로운 이름으로 .pptx 파일을 저장한 뒤 닫고 다시 엽니다.

| 포함 방식 | 적합한 용도 | 주의사항 |
| --- | --- | --- |
| 프레젠테이션에 사용된 문자만 포함 | 주로 열람할 파일, 용량 관리가 중요한 경우 | 상대방이 새 문자를 입력할 때 동일한 글꼴 적용이 제한될 수 있음 |
| 모든 문자 포함 | 다른 사용자가 문구까지 수정해야 하는 공동 작업 | 파일 크기가 커질 수 있고 글꼴 라이선스 제한은 여전히 적용 |

실제 설정 화면에 보이는 문구는 Office 버전과 언어 설정에 따라 다를 수 있습니다. **‘모든 문자 포함’은 모든 글꼴의 포함이 무조건 가능하다는 뜻이 아닙니다.** 글꼴 제작자가 정한 포함 권한이 우선합니다.

## 4단계. Mac용 PowerPoint라면 별도 저장 설정 확인하기

Mac용 Microsoft 365 PowerPoint, Mac용 PowerPoint 2024 및 2021에서도 지원되는 글꼴 포함 기능을 사용할 수 있습니다. 그러나 Windows용 **파일 → 옵션** 경로를 그대로 찾으면 안 됩니다.

1. macOS의 **PowerPoint → 기본 설정(Preferences)**을 엽니다.
2. **출력 및 공유 → 저장**에 해당하는 항목을 확인합니다.
3. 글꼴 포함(Font Embedding) 옵션이 표시되는지 확인하고 해당 파일의 포함 설정을 조정합니다.
4. 복사본을 저장한 후 다시 열어 글꼴과 줄바꿈을 검사합니다.

Mac의 글꼴 정보는 macOS **서체 관리자(Font Book)**에서 확인할 수 있습니다. 글꼴을 선택하고 정보 화면에서 포함 권한 관련 항목이 제공되는지 살펴보세요. 모든 글꼴의 권한 정보가 항상 표시되는 것은 아닙니다.

웹용 PowerPoint에는 데스크톱 버전과 다른 기능 제한이 있으므로, 위 데스크톱 글꼴 포함 경로가 웹에 그대로 존재한다고 가정하면 안 됩니다. 웹 편집 환경만 이용할 수 있다면 원본 제작자에게 포함 설정 또는 호환 글꼴 수정을 요청하는 편이 안전합니다.

## 5단계. ‘일부 글꼴을 저장할 수 없습니다’ 오류 해결하기

글꼴 포함을 켰는데 저장 시 오류가 뜬다면 설정을 반복해서 누르기보다 **글꼴 자체의 포함 가능 여부**를 먼저 확인해야 합니다. Microsoft가 안내하는 주된 이유는 두 가지입니다.

- 지원하지 않는 글꼴 형식: 일부 구형 PostScript Type 1 또는 AAT 등의 글꼴은 적합하지 않을 수 있습니다.
- 제작자의 사용 권한: TrueType(.ttf)·OpenType(.otf) 형식이어도 제작자가 파일 포함을 제한할 수 있습니다.

Windows에서는 **제어판의 글꼴**에서 해당 글꼴을 선택해 ‘글꼴 포함 가능성(Font embeddability)’ 정보를 살펴볼 수 있습니다.

| 표시되는 권한 | 의미 |
| --- | --- |
| Editable / Installable | PowerPoint에 포함할 수 있는 유형 |
| Preview/Print | 포함은 가능해도 글꼴이 없는 기기에서는 열람·인쇄 중심으로 제한될 수 있음 |
| Restricted / No embedding | 파일에 포함할 수 없음 |

포함 금지 글꼴을 임의로 우회하거나 라이선스가 불명확한 파일을 배포하지 마세요. 반드시 같은 디자인을 유지해야 한다면 **글꼴 사용권을 확인한 뒤 허용된 대체 글꼴로 변경**하거나, 편집이 필요 없는 수신자에게는 PDF를 전달하는 방법을 고려하세요.

PowerPoint에서 글꼴을 바꿨는데 경고가 계속 뜨는 상황도 있습니다. Microsoft는 일부 복잡한 문자 체계를 지원하는 글꼴에서 실제 사용 여부와 경고가 일치하지 않을 수 있다고 설명합니다. 이때는 파일을 새로 저장하고 다시 열어 화면과 실제 텍스트를 확인하되, 경고가 사라졌다고 해서 다른 기기에서 정상 표시된다는 뜻으로 받아들이지 마세요.

## 6단계. 글꼴을 바꿔야 할 때 레이아웃까지 점검하기

글꼴을 교체하면 글자폭, 자간, 줄 높이와 문단 길이가 달라질 수 있습니다. 글꼴 이름만 바뀌고 문장이 한 줄 더 늘어난다면 텍스트 상자의 크기나 줄바꿈을 다시 조정해야 합니다.

1. 먼저 제목 하나와 본문 하나에 대체 글꼴을 시험합니다.
2. 제목이 이미지나 아이콘과 겹치지 않는지 확인합니다.
3. 긴 문단과 표의 셀 안에서 마지막 글자가 잘리지 않는지 확인합니다.
4. 숫자·영문·한글·기호가 섞인 슬라이드를 따로 봅니다. 일부 글꼴은 필요한 문자를 모두 지원하지 않을 수 있습니다.
5. 결과가 만족스럽다면 다른 슬라이드로 변경 범위를 넓힙니다.

슬라이드 마스터에서 글꼴을 바꾸려면 **보기 → 슬라이드 마스터 → 글꼴**에서 머리글·본문에 적용할 글꼴 쌍을 설정합니다. 테마와 마스터를 사용하는 자리 표시자에 효과적이지만, 텍스트 상자마다 직접 지정한 글꼴까지 항상 일괄 교체되는 것으로 기대하지 마세요. 기존 테마의 디자인 요소를 보존해야 한다면 마스터도 복사본에서만 변경합니다.

모양이 달라졌다는 이유로 글자 크기를 무조건 줄이지 않는 것이 좋습니다. 발표 화면에서 가독성이 떨어질 수 있기 때문입니다. 한두 단어만 넘친다면 문구를 간결하게 바꾸고, 행간·텍스트 상자 크기·여백을 함께 조절하는 편이 나을 수 있습니다.

## 7단계. 발표용과 편집용 파일을 분리해 전달하기

상대방이 **읽기만 하면 되는지, 직접 수정해야 하는지**에 따라 정답이 다릅니다.

- **상대방이 내용을 수정해야 한다면:** 글꼴 포함 또는 허용된 대체 글꼴을 적용한 PPTX를 전달합니다. 수정할 컴퓨터에서 직접 확인해야 합니다.
- **레이아웃을 그대로 보여 주면 된다면:** PPTX 원본과 별도로 PDF를 내보내 전달합니다. PDF는 PowerPoint가 없어도 문서 레이아웃을 확인하기 좋습니다.
- **발표 애니메이션·전환·미디어가 중요하다면:** PDF만 전달하면 발표 동작을 그대로 재현할 수 없습니다. 발표용 PPTX를 실제 재생 장치에서 시험하세요.

Windows용 PowerPoint에서 PDF를 만들려면 보통 **파일 → 내보내기 → PDF/XPS 문서 만들기**를 사용합니다. Mac에서는 **파일 → 다른 이름으로 저장 → PDF** 또는 **파일 → 내보내기 → PDF**를 사용할 수 있습니다. 웹용 PowerPoint에서도 지원되는 PDF 다운로드 메뉴를 확인할 수 있습니다.

PDF는 슬라이드 화면과 레이아웃을 보존하는 공유 형식이지만, PPTX의 개별 편집 기능, 동영상 재생, 전환 효과를 그대로 제공하는 파일은 아닙니다. 또한 Mac용 PowerPoint에서 만든 PDF는 하이퍼링크가 유지되지 않을 수 있으므로, 링크가 중요한 자료라면 최종 PDF의 링크를 직접 점검하세요.

## 8단계. 저장한 파일을 다른 환경에서 재검증하기

파일을 저장한 것과 문제가 해결된 것은 다릅니다. 다음 검증을 마친 뒤 상대방에게 전달하는 것이 안전합니다.

- [ ] 원본 .pptx를 삭제하지 않고 별도 보존했나요?
- [ ] 수정한 파일을 닫았다가 다시 열었나요?
- [ ] 제목, 본문, 표, 도형 속 한글과 특수문자가 정상인가요?
- [ ] 글자가 잘리거나 텍스트 상자 밖으로 벗어나지 않나요?
- [ ] 발표할 PC 또는 상대방의 PC에서 실제 파일을 열어 봤나요?
- [ ] 발표 모드에서 각 슬라이드의 배치를 확인했나요?
- [ ] PDF가 필요한 경우, 내보낸 PDF의 글꼴·페이지·링크를 확인했나요?
- [ ] 상대방의 편집 가능 여부와 글꼴 라이선스를 확인했나요?

상대방 컴퓨터를 사용할 수 없다면 직접 확인했다고 주장할 수 없습니다. 그 경우 **PDF 미리보기본과 PPTX를 함께 전달하고, 최종 발표 전에 수신자가 확인하도록 안내**하세요.

## 자주 묻는 질문

### Q. PPTX에 글꼴을 포함하면 상대방 PC에 폰트를 설치하지 않아도 되나요?

포함 가능한 글꼴이 정상 저장되고 수신 환경에서 지원되면 동일한 모양으로 표시하는 데 도움이 됩니다. 하지만 포함 권한, 글꼴 형식, 편집 제한, PowerPoint 버전의 차이가 있으므로 항상 보장되지는 않습니다. 중요한 발표라면 수신 기기에서 직접 확인해야 합니다.

### Q. 파일 용량이 갑자기 커졌는데 오류인가요?

글꼴 전체를 포함하면 파일이 커질 수 있습니다. 공동 편집이 필요 없는 자료라면 프레젠테이션에 사용된 문자만 포함하는 옵션을 검토할 수 있습니다. 다만 파일 용량을 줄이기 위해 모든 글꼴 포함을 끄면 다른 컴퓨터에서 서체가 바뀔 위험이 다시 생길 수 있습니다.

### Q. 윈도우에서는 멀쩡한데 Mac에서만 깨지는 이유는 무엇인가요?

사용 가능한 글꼴, 글꼴 버전, PowerPoint 구현 환경이 서로 다르기 때문일 수 있습니다. Mac용 PowerPoint에서도 지원되는 글꼴 포함 기능을 점검하고, 필요한 글꼴의 설치 및 포함 허가 여부를 확인한 뒤 테스트하세요. Windows 메뉴 경로를 Mac에 그대로 적용하지 마세요.

### Q. 글꼴 대신 슬라이드를 이미지로 만들어 넣으면 완벽한가요?

이미지는 편집 가능한 글자를 잃게 되고 해상도와 접근성 문제가 생길 수 있습니다. 장면의 외형을 고정하려는 특수한 경우를 제외하면, 원본 PPTX를 유지하고 열람용 PDF를 추가하는 편이 일반적으로 실용적입니다. 이미지로 만든 텍스트는 검색·복사·화면 읽기에도 불리할 수 있습니다.

### Q. 글꼴을 바꾸면 슬라이드 마스터도 수정해야 하나요?

공통 테마의 제목·본문이 영향을 받았다면 마스터를 확인하는 것이 좋습니다. 반면 특정 텍스트 상자만 문제라면 그 개체의 직접 서식이 원인일 수 있습니다. 두 경로를 구분하지 않고 일괄 수정하면 멀쩡한 슬라이드까지 바뀔 수 있습니다.

## 결론: 글꼴 포함보다 중요한 것은 실제 받는 환경

파워포인트 글꼴 깨짐은 파일이 손상됐기 때문이라고 단정할 수 없습니다. 대부분의 진단은 **어느 기기에서, 어떤 글꼴이, 어떤 방식으로 대체되는지** 확인하는 것부터 시작합니다. Windows·Mac의 글꼴 포함 기능과 글꼴 라이선스를 확인하고, 편집용 PPTX와 열람용 PDF를 적절히 분리하세요. 최종 기준은 저장 옵션에 체크가 되어 있는지가 아니라 **받는 사람이 실제로 열었을 때 글자와 배치가 올바르게 보이는지**입니다.
